Set your API key

This app runs on your own Vercel AI Gateway key. Usage is billed to your own Vercel account (free while within the free credits).

  1. Create an account at vercel.com.
  2. Go to AI Gateway → API Keys → Create Key (the key is shown only once).
  3. Free credits require adding a card. Adding a card alone does not charge you.
  4. We recommend setting a spending limit under AI Gateway → Budgets (e.g. $5).

Your key is stored only on this device and is sent only to Vercel.
